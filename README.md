# Math Study Helper
교안을 기반으로 예시 문제를 만들고, 풀이 중 막힌 부분에 힌트를 주는 학습 도구

## 기능
- 교안(.md) 내용만을 근거로 연습 문제를 생성해줌
- 막힌 부분을 입력하면 정답 및 해설 대신 다음으로 할 수 있는 다음 단계의 힌트 하나를 알려줌

## 실행 방법
1) 'pip install anthropic python-dotenv'
2) '.env' 파일에 'ANTHROPIC_API_KEY=...' 작성함
3) 'python3 main.py'

## 개발 기록...
### v1: 교안 읽기, 문제 생성, 힌트 제공
- **문제점**: 응답의 첫 블록이 'ThinkingBlock'일 때, '.text' 접근 에러가 발생함
- **해결방안**: 응답 블록 중 type이 "text"인 것만 추출하는 'get_text()' 함수를 도입함
- **추가 조치**: 'max_tokens' 상향함(생각하는 데 쓰인 토큰도 포함될 수도 있기 때문에 처음에 잡은 4-500 토큰으로는 답이 잘릴 수도 있기 때문)
